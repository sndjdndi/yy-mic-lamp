# YY 麦克风灯

玩游戏时，不想每次切回 YY 窗口开关自由麦？这个小工具提供一个可拖动、置顶的悬浮灯，点击即可切换 YY 的持续自由发言。

## 使用

1. 打开 YY 并进入语音频道。
2. 下载 [YY麦克风灯.exe](dist/YY麦克风灯.exe)，直接双击运行，无需安装。
3. 点击灯切换：**绿色**表示自由麦已开启，**红色**表示持续自由发言已关闭；灰色问号表示暂未连接到 YY。
4. 拖动悬浮窗调整位置；下方音量条随麦克风输入变化，关麦时归零。橙点表示尚未检测到 YY 音频输入。
5. 双击右下角托盘图标可收起或显示悬浮窗，右键可切换“游戏置顶模式”或打开日志文件夹。点击“退出”关闭工具；收起和退出均保留 YY 当前发言状态。

## 日志与隐私

程序默认记录启动、YY 连接诊断、麦克风开关状态变化、切换结果和错误码。日志保存在 `%LOCALAPPDATA%\YYMicLamp\Logs`，可从托盘右键菜单的“打开日志文件夹”查看。日志不包含录音、账号、频道名称、窗口位置或音量采样；单个日志超过 1 MB 时会轮换保留上一份。

## 说明

- 通过 Windows 辅助功能接口调用 YY 自身的按钮，不持续按住 F2，也不依赖固定屏幕坐标。红灯仅关闭持续自由发言，YY 原有的按键说话仍可使用。
- 请以普通权限运行麦克风灯，与通常以普通权限运行的 YY 保持一致；不要在 Windows 兼容性设置中强制“以管理员身份运行”。若显示问号，可先查看日志中的 `YY_WAITING` 原因。
- 音量条读取 YY 音频输入的音量信息，不录音；它不能保证其他人已经听到你的声音。
- 适用于 Windows，已在 YY 9.59 和窗口化游戏中验证。若游戏中看不到悬浮窗，可使用无边框或窗口模式；其他 YY 版本可能需要适配。

## 从源码构建

使用 Windows PowerShell 运行 `./build.ps1`，生成文件位于 `dist/YY麦克风灯.exe`。使用系统 .NET Framework 编译器，无需安装额外开发工具。
